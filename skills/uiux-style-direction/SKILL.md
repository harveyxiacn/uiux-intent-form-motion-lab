# Set the look

Start from the page purpose, audience, content and the user's stated aesthetic. Inspect the existing interface when refining it. Treat references as evidence to analyze rather than assets to copy or a reason to replace an established identity.

Identify the specific visual ingredients that produce the reference's effect: composition and hierarchy, type scale and character, color roles, imagery or material, spacing, shapes and depth. Translate observations into actionable choices for the actual content. For example, “an orange ribbon crossing four staggered photographs” specifies more than “creative and playful.” Avoid inventing claims or image rights.

Present a compact direction: intent, first-screen composition, color roles, typography, image treatment, reusable component characteristics and responsive adaptation. Explain which choices support the user's goal. When references disagree, select a coherent direction rather than merging every motif; preserve requested constraints.

If the user requests implementation, use existing design tokens and components where appropriate, then inspect the rendered result at relevant viewport sizes and correct visible issues. If browser verification is unavailable, state that limitation. For planning-only work, provide the direction without modifying the interface.
