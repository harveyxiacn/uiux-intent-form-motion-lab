慢半拍是一座虚构的互动展览馆。本期展览以「日常的另一面」为题，把拍手的回声、陌生的声音和一扇没有目的地的门，变成可以亲身参与的作品。

这里没有唯一的参观路线，也不要求你读懂每件作品。你可以停留、倾听，和同行的人交换一种全新的发现。

「当我们暂时放下目的，

策展从一个简单的问题开始：如果生活中最普通的动作，也能成为一件作品呢？展览用可触摸的材料、可回应的空间与开放的叙事，让观众从旁观者变成作品的一部分。

三个展室不是闯关，也没有完成标准。它们像三个提问，等待每个人用自己的经历作答。

适合带孩子一起参观吗？

概念展览面向所有对日常保持好奇的观众。儿童建议由成年人陪同参与；部分声音装置可能产生突发声音，可按个人感受选择参观。

需要按固定顺序参观吗？

不需要。三个展室彼此独立，你可以从最感兴趣的作品开始，也可以随时回到喜欢的空间。建议预留 60—90 分钟。

可以触摸作品、拍照吗？

标明可参与的装置鼓励你动手体验，其余作品请按现场说明参观。概念场馆允许个人非商业拍照，建议关闭闪光灯，避免影响他人。
