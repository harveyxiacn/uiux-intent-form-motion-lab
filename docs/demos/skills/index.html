自我说明 / METHOD TRACE

这页本身，
就是八个设计模块的练习。

上游六个 Skill 用展台转述；本项目八个设计模块与提示词手册直接参与这页的规划、视觉、状态、动效与审查。下面是它们各自做的决定。

  1. 01
    页面规划

    先决定这是一张“可操作的方法地图”，不是作品集：首屏给主张与数量，第二屏给六个展台，第三屏给完整索引。

    看展台
  2. 02
    视觉方向

    暖纸、墨黑、橙色行动与紫色数据标记；实验室网格与等宽标签建立“正在运行”的语感。

    看首屏
  3. 03
    交互规格

    每个展台只回答一个问题，输入后立即反馈；切换、抽取、审查、修复都有明确的结果状态。

    试交互
  4. 04
    设计系统

    颜色、间距、圆角、字号和状态全部走语义 token；深色主题只换角色，不换结构。

    看系统
  5. 05
    组件工程

    展台、结果卡、过滤器和索引条目来自同一套数据结构；切换只看状态，不重建页面。

    看索引
  6. 06
    动效工程

    只在数据变化时给短过渡；不排队、不阻塞结果；减少动态时直接到最终状态。

    抽方向
  7. 07
    无障碍审查

    键盘可完成 tab、过滤、审查与修复；状态用 live region 播报；焦点始终可见；正文保持 4.5:1。

    跑审查
  8. 08
    移动模式

    手机端单列展台、横向可滚的筛选、44px 触控目标；不是把桌面缩窄，而是重排任务顺序。

    看窄屏
