# 展台设计简报

## 目标与信息结构

这是作品与方法的内容型展览官网，受众是想理解 UI/UX 方法并亲手检查交互的设计师、开发者与学习者。第一屏先建立「界面值得体验」的主张，以四张项目真实截图展示内容；主要行动是选择作品进入现场体验。页面顺序：大标题与截图相册 → 六类作品索引 → 技能地图专题 → 案例介绍与内嵌现场 → 八种本地方法的三个阶段 → 回到现场。不会把整个网站压缩为顶部选择器和一个 iframe。

## 可复用的设计提示词

设计一座可以亲手探索的界面作品展。暖白纸面、墨黑超大中文标题，鲜橙丝带横穿标题下部，淡紫可揭贴纸作为局部互动。用项目自身四张不同界面截图组成错落的相册，让截图成为视觉主体；图片保持清晰，边角轻微旋转，点击后进入对应案例。文案精炼，说明作品做什么、为什么这样做，而非罗列实现名词。中段提供六类作品导航，其中「技能地图」进入深色专题区：左侧是真实首屏截图，右侧解释十四个 Skill 如何各自留下可操作证据；再往下是可操作现场。下段以意图、形态、交互三段编辑式布局解释八个本地方法。避免八张一样的小卡片。手机重新构图成两列截图，标签可换行，内嵌手机案例使用手机框，其他案例占满可用宽度。

## 视觉方向与系统

- 标题 `让界面 / 值得体验。` 使用本机中文粗体，桌面10.6vw、手机65px；正文16px。大字、内容段、作品截图共同建立层级。
- `--paper` 暖白 `#f4f2ec`、`--ink` 墨黑 `#191a18`、`--orange` 鲜橙 `#ff713c`、`--violet` 淡紫 `#b3a2fa`。深主题单独定义纸面/文字/表面/焦点角色，贴纸和丝带保持原色。
- 相册由本项目 `web-desktop`、`studio-dark`、`app-mobile`、`components-desktop` 四张截图组成；没有远程图片或外部字体依赖。
- 作品目录为六列文字索引，手机改纵向条目；第六项进入技能地图专题，专题用墨黑底、纸色文字和橙色行动色，与前后暖白区形成换气。方法区用三块不同色面承载 2+3+3 个本地方法，而非均匀卡片网格。

## 八个方法在此页面中的应用

1. 页面规划：明确内容网站分类，阅读与探索优先；现场体验嵌在完整叙事之中。
2. 视觉方向：超大中文、橙色纸带、截图相册、紫色贴纸形成明确构图，而非工具壳。
3. 交互规格：案例选择同步tab、说明、iframe、独立打开和hash；第六标签进入技能地图；贴纸可揭起、移动、落平、反向还原。
4. 设计系统：双主题语义色、统一边距、标题与段落层级、按钮选择态、focus边界；主题通过同源 postMessage 同步给内嵌技能地图。
5. 组件工程：一个案例数据映射驱动所有选择入口；保留tab原生按钮、aria-selected、tabpanel关联；只有案例更换才重载iframe；技能地图自身再用一个14条数据映射驱动索引与筛选。
6. 移动模式：本页仍是响应式网站，不称手机app；真正的手机原型在现场中独立呈现手机尺寸；技能地图在手机单列重排展台。触控有等价点击，不依赖hover。
7. 动效工程：650ms贴纸近似卷角，右下角扩大、整体抬起旋转、向槽移动、角归零。读取当前画面后取消旧animation并重定向，业务目标不等待animation事件。减少动态效果时直接到最终位置。
8. 无障碍复核：skip link、明确图片替代文字、tab左右/Home/End键、可见focus、贴纸pressed与状态播报、文字不依赖颜色区分；技能地图只用单一status live region，避免重复播报。

## 关键交互契约

- 初始tab为web；hash支持web/dashboard/app/studio/components/skills。点击截图/目录或专题按钮会选择对应案例、滚动到现场并把焦点放到选中tab。tab本身切换不跳动页面。
- 案例iframe使用 `loading=lazy`；只有滚动到现场附近才加载。技能地图使用更高的900px舞台，手机为760px，内部页面自行滚动。
- 贴纸 `#peel-sticker` 初始在槽上方，`aria-pressed=false`。激活后角从23px扩大至52px，整体抬起并旋转，移动15px/43px至虚线槽，最后收平到82px高。再次激活反向回原位；快速重复重定向而非排队。
- 贴纸是可逆装饰互动，不解锁内容、不改变案例、不阻止阅读。
- `prefers-reduced-motion` 禁止平滑滚动、贴纸旅行和hover位移；内容、选择态、pressed、播报全部保留。
- 主题切换即时更新语义角色，不增加大面积遮罩动画，降低阅读干扰。

## 验证范围

`node --check docs/showcase.js` 与技能地图的 `data.js` / `app.js` 已通过。桌面/手机截图、贴纸中间帧和技能地图内嵌截图由本轮浏览器检查记录；最终验收以集成记录为准。本页不声称WCAG认证或真机测试。内嵌原型没有服务器功能，界面已注明。

### 本轮视觉复核记录

桌面1440、平板768、手机390的首屏及整页检查图均已逐张打开。手机贴纸单独位于标题下方，保留标题完整；四张真实项目截图构成两列相册；六类索引与墨黑技能地图专题形成清楚的阅读层级；方法区三块大色面保持原有节奏。首屏不再是选择器与iframe工具壳。

技能地图本身也做了独立复核：桌面与手机标题都保持两行，手机390宽无横向溢出；六个展台按内容自动分配 6/6、5/7、7/5 的列宽，窄屏全部单列。深色首屏、第六标签内嵌状态与代表文本对比度均有截图/JSON证据。

本轮证据为 Playwright 行为断言、代表文本对比度 JSON 与实际截图目视；不把自动检查或人工判断扩展为通用审美结论或 WCAG 认证。
