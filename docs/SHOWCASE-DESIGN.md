# 展台设计简报

## 目标与信息结构

这是作品与方法的内容型展览官网，受众是想理解 UI/UX 方法并亲手检查交互的设计师、开发者与学习者。第一屏先建立「界面值得体验」的主张，以四张项目真实截图展示内容；主要行动是选择作品进入现场体验。页面顺序：大标题与截图相册 → 五类作品索引 → 案例介绍与内嵌现场 → 八种方法的三个阶段 → 回到现场。不会把整个网站压缩为顶部选择器和一个 iframe。

## 可复用的设计提示词

设计一座可以亲手探索的界面作品展。暖白纸面、墨黑超大中文标题，鲜橙丝带横穿标题下部，淡紫可揭贴纸作为局部互动。用项目自身四张不同界面截图组成错落的相册，让截图成为视觉主体；图片保持清晰，边角轻微旋转，点击后进入对应案例。文案精炼，说明作品做什么、为什么这样做，而非罗列实现名词。中段提供五类作品导航和可操作现场，下段以意图、形态、交互三段编辑式布局解释八个方法。避免八张一样的小卡片。手机重新构图成两列截图，标签可换行，内嵌手机案例使用手机框，其他案例占满可用宽度。

## 视觉方向与系统

- 标题 `让界面 / 值得体验。` 使用本机中文粗体，桌面10.6vw、手机65px；正文16px。大字、内容段、作品截图共同建立层级。
- `--paper` 暖白 `#f4f2ec`、`--ink` 墨黑 `#191a18`、`--orange` 鲜橙 `#ff713c`、`--violet` 淡紫 `#b3a2fa`。深主题单独定义纸面/文字/表面/焦点角色，贴纸和丝带保持原色。
- 相册由本项目 `web-desktop`、`studio-dark`、`app-mobile`、`components-desktop` 四张截图组成；没有远程图片或外部字体依赖。
- 作品目录为五列文字索引，手机改纵向条目；方法区用三块不同色面承载 2+3+3 个方法，而非均匀卡片网格。

## 八个方法在此页面中的应用

1. 页面规划：明确内容网站分类，阅读与探索优先；现场体验嵌在完整叙事之中。
2. 视觉方向：超大中文、橙色纸带、截图相册、紫色贴纸形成明确构图，而非工具壳。
3. 交互规格：案例选择同步tab、说明、iframe、独立打开和hash；贴纸可揭起、移动、落平、反向还原。
4. 设计系统：双主题语义色、统一边距、标题与段落层级、按钮选择态、focus边界。
5. 组件工程：一个案例数据映射驱动所有选择入口；保留tab原生按钮、aria-selected、tabpanel关联；只有案例更换才重载iframe。
6. 移动模式：本页仍是响应式网站，不称手机app；真正的手机原型在现场中独立呈现手机尺寸。触控有等价点击，不依赖hover。
7. 动效工程：650ms贴纸近似卷角，右下角扩大、整体抬起旋转、向槽移动、角归零。读取当前画面后取消旧animation并重定向，业务目标不等待animation事件。减少动态效果时直接到最终位置。
8. 无障碍复核：skip link、明确图片替代文字、tab左右/Home/End键、可见focus、贴纸pressed与状态播报、文字不依赖颜色区分。

## 关键交互契约

- 初始tab为web；hash支持web/dashboard/app/studio/components。点击截图/目录会选择对应案例、滚动到现场并把焦点放到选中tab。tab本身切换不跳动页面。
- 贴纸 `#peel-sticker` 初始在槽上方，`aria-pressed=false`。激活后角从23px扩大至52px，整体抬起并旋转，移动15px/43px至虚线槽，最后收平到82px高。再次激活反向回原位；快速重复重定向而非排队。
- 贴纸是可逆装饰互动，不解锁内容、不改变案例、不阻止阅读。
- `prefers-reduced-motion` 禁止平滑滚动、贴纸旅行和hover位移；内容、选择态、pressed、播报全部保留。
- 主题切换即时更新语义角色，不增加大面积遮罩动画，降低阅读干扰。
